# PWA 登入方式選擇修正

## 問題

CoachLog 加入手機主畫面後，PWA 會依照 manifest 的 `start_url: "/local"` 直接進入本機模式。本機模式本身也沒有登入入口，因此使用者無法選擇 Google 登入。

## 設計

- 將 PWA 的 `start_url` 改為 `/`，讓主畫面 App 與一般瀏覽器共用同一個入口。
- 未登入時，首頁維持現有的「不用登入，直接使用」與「登入 Google 帳號」兩種選擇。
- 已登入時，首頁維持現有行為，自動導向 `/dashboard`。
- 本機模式頂端加入「登入 Google 帳號」連結，讓已進入本機模式的人仍可切換使用方式；不變更或自動上傳既有本機資料。
- 雲端模式維持現有「登出」按鈕，登出後回到 `/`。

## 測試

- 更新 `scripts/check-pwa-navigation.mjs`，要求 PWA 從 `/` 啟動。
- 測試本機模式具有可返回 `/` 的登入選擇入口。
- 執行專案既有測試與 `npm run build`，確認導覽及 Next.js 建置正常。

## 不在本次範圍

- 不自動合併或上傳本機資料至雲端。
- 不改動 Google OAuth、資料庫或 Google Calendar 同步邏輯。
